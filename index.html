Engineered for Simplicity & Autonomy

Everything you need for private, reliable, and verifiable team or personal communication.

Pull-Based Federation (SOMFP)

Unlike traditional federated networks where node downtime causes lost events, SOMFP treats push notifications as advisory. Servers pull compacted state feeds and catch up deterministically after network partitions.

No Heavy Middleware

No Redis, Kafka, or RabbitMQ clusters required. The entire backend runs on NestJS and PostgreSQL using ACID-backed durable transactional queues, keeping deployment memory footprints under 150MB.

Cross-Platform with Rust Runtime

Native clients for Android, Linux, Windows, and macOS built with Tauri. Platform UI remains a thin adapter while shared Rust code owns connection epochs, cryptographic validation, and synchronization.

1:1 WebRTC Voice & Video

Direct peer-to-peer audio and video calls with real-time signaling passed transparently across federated server boundaries.

Durable Deletions (Tombstones)

Message retraction and account removal use explicit tombstone events with monotonically increasing sequence cursors, ensuring deletions propagate completely across all peering nodes.

Pixel-Accurate Virtual Scrolling

The web client features a specialized integer-pixel virtual chat-box engine that prevents layout shifts, scroll jumps, and measurement drift across millions of messages.

Protocol Architecture

SOMFP (Simple Open Messaging Federation Protocol)

An open specification designed specifically for federated chat without the complexity of Matrix state resolution or XMPP XML streams.

1. State Feed Pull

Peering servers sync latest heads using /somfp/v1/state-feed. State feeds are compacted so intermittent nodes only need to pull latest checkpoints.

2. On-Demand Message Query

Large message bodies and rich media remain localized and are fetched via /somfp/v1/messages only when participating users request thread views.

3. Cryptographic Epochs

Ed25519 signatures authenticate server-to-server requests. Key rotations and identity domain rebinds are tracked deterministically across the mesh.

Deploy Your Own Node in Minutes

Run SOMS on your home server, VPS, or NAS. A single Docker Compose command spins up Caddy (with automatic TLS), the NestJS API server, and PostgreSQL.
