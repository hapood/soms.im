Discover the peer, establish recognition, then exchange signed requests over HTTPS.

01

HTTPS protects the link

Hostname-verified HTTPS encrypts transport and authenticates the responding endpoint. This is not user-to-user end-to-end encryption.

02

Recognition establishes trust

Servers validate discovery documents, root-authorized signing certificates, and local admission policy. A recognized result confirms acceptance; pending does not.

03

Requests stay authenticated

HTTP Message Signatures authenticate requests. Content digests bind the body, and time-window checks limit replay. Each operation still requires authorization.
